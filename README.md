# cris-website

The Cris website. Plain HTML and CSS, no build step, published by Netlify. Started from the `starter-paper` kit in [web-style-guide](https://github.com/cRistringss/web-style-guide).

Built only from the design system in [cris-design-system](https://github.com/cRistringss/cris-design-system). Read `CLAUDE.md` first.

Pages: `index.html` · `pricing.html` · `about.html` · `contact.html` · `thanks.html`. `storybook.html` is served at `/storybook`.
